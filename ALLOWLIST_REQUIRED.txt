# Cowork egress allowlist — required for the daily KB refresh
#
# Why this file exists
# --------------------
# The scheduled task `banking-kb-daily-refresh` runs inside Cowork's sandbox.
# Cowork enforces a per-workspace egress allowlist on the outbound proxy
# (HTTP 403 with header `X-Proxy-Error: blocked-by-allowlist`).
#
# As of 2026-05-19, the allowlist only contains:
#     *.anthropic.com, anthropic.com, claude.com, *.claude.com,
#     endpoint4.collection.sumologic.com
#
# Every domain the engine needs to fetch from is blocked, so the refresh
# fails on the first HTTP call (NSE warmup) and no log is written.
#
# How to fix (one-time)
# ---------------------
# 1. Open Claude desktop → Settings → Capabilities → Network access.
#    (On Team/Enterprise plans this is an admin setting; ping your workspace
#    owner.)
# 2. Add every domain below to the allowlist. Wildcards on subdomains are
#    fine if the UI supports them (e.g. `*.bank.in` covers the Bank.in
#    bundle).
# 3. Re-run the scheduled task (or trigger `banking-kb-daily-refresh`
#    manually). The engine is idempotent, so it's safe to re-run.
#
